# Rescue Arc Frontend — SIH Problem 26191: Red Zone Intelligence & Relocation Platform

## 🌿 Fresh Natural White & Light Green Design System

The Rescue Arc frontend features a scrollable, high-impact marketing experience built with Next.js 15, Tailwind v4, and custom geospatial red zone intelligence components for SIH Problem 26191.

### 🎨 Theme & Color Variables (`src/app/globals.css`)
- `--bg-light-white`: `#ffffff` (Pure crisp white backgrounds)
- `--bg-light-sage`: `#f0fdf4` (Light sage green section container backdrops)
- `--bg-light-mint`: `#e6f4ea` (Soft mint accents)
- `--forest-pine`: `#064e3b` (Deep evergreen text & headings)
- `--forest-leaf`: `#059669` (Fresh leaf green highlights)
- `--earth-amber`: `#d97706` (Seismic, landslide & warning highlights)
- `--authority-navy`: `#1e3a8a` (NDMA & official authority badge slate navy)

### 🧩 Marketing Page Components (`src/components/marketing/`)
- `Navbar.jsx`: Translucent white/sage navigation bar with smooth scroll anchors (`#home`, `#authorities`, `#features`, `#how-it-works`, `#impact`) and NDMA 1078 helpline button.
- `Home/HomeSection.jsx`: Scrollable hero section with real-time red zone monitor, settlement risk status dashboard, and impact stat cards.
- `Authority/AuthorityHubSection.jsx`: Dedicated NDMA, DDMA, GSI, and Central Water Commission authority coordination matrix.
- `Features/FeaturesSection.jsx`: Red zone intelligence switcher (Flood Zones, Seismic Zones, Landslide Susceptibility, Carrying Capacity, Relocation Priority).
- `HowItWorks/HowItWorkSection.jsx`: 5-step red zone assessment & relocation pipeline.
- `Impact/ImpactSection.jsx`: Red zone classification metrics and authority onboarding CTA.
- `footer.tsx`: Light green multi-column footer with emergency numbers & red zone intelligence links.

## 🚀 Running the Frontend

Run from root directory or `frontend/` directory using `pnpm`:

```bash
pnpm dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
